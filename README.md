# SWEEPER / C

B_SWEEPERを基準にしたC版プロトタイプ。

## C版の修正
- バトル画面から独立した「2D CHARACTER MOTION」セクションを削除。
- バトル画面を1画面に収めるレスポンシブ構成へ変更。
- チップを3列×2行のコンパクトUIに固定。
- チップ選択は `pointerup` で確実に処理。
- 攻撃判定をチップごとに分離。
  - ソード：正面1マス / 40ダメージ
  - ショット：正面3マス以内 / 20ダメージ
  - シールド：正面からの次のダメージ50%軽減
  - ダッシュ：正面2マス移動
  - リカバー：HP30回復
  - レン / オーバーブレード：次の攻撃+50、使用後1ターン待機
  - カイ / アクセルステップ：2マス移動、次の攻撃+10
- 通常攻撃もレン/カイとも正面1マスに統一。
- 2Dモーションはバトルフィールド上のキャラクター自身だけで再生。
- B版に含まれていた2Dドットの既存フレームをコード処理で背景透過し、余白・番号・隣接フレームの不要部分を除去。
- 新規キャラクター画像・モーション画像の生成は行っていない。
